# ScamPlay product vision — all planned features, not all approved for build

**Mission:** Khmer/English entertainment-based digital safety education for the Cambodian public, focused on (1) recognizing scams, (2) protecting accounts, devices, identity and money, and (3) responding immediately when victimized.

**Platforms:** Flutter Android/iOS for citizens; Next.js admin web for authorized staff; central Supabase PostgreSQL; local SQLite cache in Flutter; shared constrained APIs.

## Eight modules — full scope
1. **Scam News:** local/international approved sources; deduplication; source URL/date; Khmer and English summaries/translations; editorial review and provenance; thumbnail license checking; scheduled ingestion later.
2. **Educational Videos:** authorized uploaded or embedded instructional video; image covers, subtitles/transcripts, bilingual title/description, categories, admin publishing; rights documented.
3. **AI Lab:** authenticated opt-in help analyzing suspicious messages/screenshots/URLs/phone indicators; uncertainty explicitly displayed; no safety guarantees, no unsafe URL fetching, privacy/cost controls; optional reputation integrations only where verified.
4. **I Have Been Scammed:** category-driven immediate safety steps, preservation and reporting guidance vetted by subject-matter experts; educational assistance not an official report submission.
5. **Contact Directory:** verified national/provincial/district/local police and bank contacts; source, last-verified date, review owner, correction reporting, geographic search; unverified records excluded from release.
6. **Scam Scenarios:** illustrated selectable library cards; sequential/branching decisions, images, prerecorded Khmer/English narration, selectable answers, feedback, replay, progress and results. One Telegram/Facebook takeover case is first complete playable case.
7. **Digital Safety Health Check:** educational question sets on MFA, privacy, passwords, Telegram, Messenger, email, devices, apps; only limited permission-respecting device checks where supported—no blanket vulnerability-scan promises.
8. **Cyber Anti-Scam Law:** official documented legal texts and accessible educational explanations; interactive matching/flashcards/quiz, narrated options, shareable lessons; later progress/certification with configurable score levels and clear non-government qualification label.

## Shared future capabilities
- Khmer default + English, content management, guest play, optional user accounts, analytics with privacy safeguards, versioned data, media library, secure backups/restore, user support, corrections, role-based admin and audit trail.
- Certificate bands if approved: 0–49 Basic, 50–69 Intermediate, 70–100 Advanced; only represent educational completion, not accreditation or identity proof.

## Important constraints
- No institutional endorsement while ownership unresolved.
- No AI output framed as guaranteed safe, no fabricated scam reporting or official contacts.
- Real production deployment requires legal/content/security approval and operational ownership.
