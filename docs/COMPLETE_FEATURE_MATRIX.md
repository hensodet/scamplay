# Eight-feature completeness / what counts as done

| Feature | Demo early | True completion definition | Milestone |
|---|---|---|---|
| Scam Scenarios | 4 illustrated cards, 1 playable first | Admin creates/publishes bilingual scenario; Flutter discovers, downloads, plays offline; reviewed scripts/audio | M3–M5B |
| I Have Been Scammed | preview | reviewed fraud-type decision tree + safe recovery steps + correction channel | M6 |
| Contact Directory | search UI prototype | sourced, reviewed contacts with last-verified, expiry/revalidation, corrections | M6 |
| Educational Videos | demo video card, rights-cleared 1 short sample later | admin uploads/embeds licensed video; preview, Khmer/English subtitles and player | M7 |
| Scam News | fictional fixture only | ingest permitted sources, source/date/provenance, dedup, Khmer translation, review, publish | M7 |
| Digital Safety Health Check | sample Q&A screen | reviewed assessment and feedback with supported, permission-based checks only | M8 |
| Cyber Anti-Scam Law | demonstration of document/card | verified texts, interactive law learning, versioning, reviewed legal explanations | M8 |
| AI Lab | information-only preview | secure user-authenticated analysis, optional screenshot/URL/phone inputs, guardrails, threat model, cost/privacy control | M10 |

Cross-cutting capabilities: Khmer/English on EVERY live item, admin roles, content approval, media licensing, optional profiles/progress and educational certificates later, analytics/feedback, backup/recovery, iOS/Android test matrix, maintenance owner.

Demo does not equal functional. Do not claim 'all eight completed' until each corresponding acceptance gate passes.
